# Contributing

Use synthetic projects and temporary profiles. Include the observable failure, the smallest complete fix and a check that protects the behavior. Do not include real notes, accounts, employer identifiers, private URLs or credentials in reports.

Keep installation coexistence, scope isolation and uninstall preservation covered. Document host versions and whether evidence is a fixture, direct command, native discovery or actual model-session dispatch. New providers and automatic writers need explicit data scopes, bounded inputs, failure retention and cost evidence.

Run the standard-library test suite and artifact builder. No model or paid API call is required for unit tests. Upstream skills remain optional and retain their own licensing boundaries.
