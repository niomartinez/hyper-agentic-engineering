# HAE identity

The symbol represents the toolkit’s workflow: three copper agent modules coordinate through a shared layered memory core, framed by ivory code brackets. Charcoal, warm ivory and copper carry the identity. The mark communicates engineering, coordination and persistence without relying on the project’s initials.
