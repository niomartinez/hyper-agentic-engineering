# Agent Memory

HAE stores readable Markdown here. Obsidian is optional. Start with the project returned by `hae context`; search narrowly instead of reading every note.

- Projects: verified scope and current decisions.
- Sessions: approved checkpoints and clearly marked historical evidence.
- Practices: selected ways of working.
- Inbox/Captures: optional unverified final-response excerpts, not instructions.
- System: local mappings and provider settings. Keep these private.

The main conversation decides what to remember. Local code saves approved text without another language model. Ordinary replies need no curated note. Explicit overrides update the scoped authoritative note using its exact previous hash; preserve dated supersession context.

Changing AI logins does not change this folder or establish authorship. Share a project handoff with other people, not this entire private memory. Uninstall preserves notes. No backup or cloud provider is enabled automatically.
